# Описание проекта RAG Checklist Assistant

Этот проект представляет собой интеллектуального ассистента для тестировщиков (QA), который помогает писать более полные и качественные чек-листы в Jira.

Главная идея: **ИИ не генерирует тесты с нуля из головы, а анализирует прошлый реальный опыт команды и подсказывает, что тестировщик мог упустить.**

### Как это работает:
1. **Тестировщик пишет черновик чек-листа в Jira** (это обязательное условие, инструмент не работает с пустыми чек-листами, чтобы тестировщики не теряли навык самостоятельного мышления).
2. **Ассистент (через Chrome-расширение)** берет текст текущей задачи и черновик чек-листа, отправляет их на бэкенд.
3. **Бэкенд (RAG-система)**:
   * Превращает задачу в вектор и ищет в локальной базе данных (PostgreSQL с расширением `pgvector`) наиболее семантически похожие **реальные задачи из прошлого опыта команды**.
   * Извлекает из них чек-листы и баги, которые там реально происходили.
   * Применяет алгоритм диверсификации, чтобы подсказки не зацикливались на одном старом кейсе.
4. **LLM (ChatGPT)** сопоставляет текущую задачу, написанный тестировщиком черновик и найденный опыт прошлого.
5. **Ассистент выдаёт точечные рекомендации**: какие пункты стоит добавить и *почему* (например: *«В задаче KAN-5 при аналогичном переносе склада забыли проверить rollback при ошибке»*).
6. При одобрении пункты добавляются в Jira с пометками происхождения: 🧑 (написано человеком) / 🤖 (подсказано ИИ).

---

### Технологический стек:
* **Frontend**: Chrome Extension (Manifest V3) — встраивает кнопку и модальное окно прямо в интерфейс Jira.
* **Backend**: FastAPI (Python), клиент к Jira REST API.
* **Database / Vector Search**: PostgreSQL + `pgvector` (запускается локально в Docker Compose).
* **AI/LLM**: OpenAI API (модель `text-embedding-3-small` для векторизации и `gpt-4o-mini` для генерации).

---

### Ключевые фичи и дизайн-решения:
* **Защита от деградации навыков (Anti-deskilling)**: инструмент требует сначала написать хотя бы один пункт самостоятельно.
* **Прозрачность (Provenance, not surveillance)**: теги 🧑 и 🤖 служат только для понимания происхождения требований и возможности повторного запуска ассистента (он не будет повторно предлагать уже принятые им пункты).
* **Конфиденциальность**: для демо-версии все Jira-задачи, чек-листы и «прошлый опыт» были полностью анонимизированы и выдуманы с нуля, чтобы не раскрывать реальные рабочие данные.
